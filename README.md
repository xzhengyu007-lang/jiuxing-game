# 九星霸体诀 · 修仙（网页放置游戏）

以平凡魔术师所著小说《九星霸体诀》（主角龙尘）为蓝本的粉丝致敬向网页修仙放置游戏。
纯静态、零依赖：双击 `index.html` 即可在浏览器中原生 JS 游玩（也可用任意静态服务器托管）。

> 本作为粉丝向同人致敬之作，仅供学习交流。境界体系、锻骨祭炼、破仙台凝神丹、
> 四极择符、九大秘藏等设定取自小说及公开资料整理，游戏文案为原创改编，不含小说原文。
> 详情见文末「资料来源与版权声明」。

---

## 一、运行方式

- **直接游玩**：双击 `index.html`（Chrome / Edge / Firefox 均可），无构建步骤、无依赖。
- **手机上游玩**：部署到 GitHub Pages 后用手机浏览器打开网址即可，支持「添加到主屏幕」与离线（见第八节）。
- 存档自动保存在浏览器 localStorage，每 10 秒自动保存；关页再开不丢进度，并有离线收益（最多 8 小时）。
- 「境界」页 → 「存档管理」可导出/导入存档码（Base64），方便换机。
- 「境界」页 → 「重置存档」可清档重来。

## 二、核心玩法循环

1. **打坐修炼**：放置自动累积灵气（离线也有收益）；「运转周天」可主动点击加速。
   **每日修为有上限**：打坐、炼丹、战斗、采药、服食所获修为共同计入「今日修为」，
   计满后当日不再增长，点「日落而息」进入次日才恢复增长。
2. **冲击境界**：22 个大境界 × 每境 13 层，共 285 层。
   - 普通层数：基础成功率约 92% 起步，随境界与层数递减；失败损失五成当层灵气。
   - 锻骨境：每层需以祭骨丹祭炼骨骼（1/2/4/6/8/10/13/16/19/22/25/28/31 根递增）——“拼的不是天赋，是财力”。
   - 璇丹境：需「破仙台凝神丹」，成功率仅 55%，失败仙台爆碎（原著设定：此境只有一次机会）。
   - 通冥境：冲关参悟生死（55%）；服「生死轮回丹」可十拿九稳。
   - 蜕凡→神火境：需「神火引」，点燃神火之种并择属性（金木水火土风雷光暗魂）。
   - 四极境：一炷香（10 秒）内自七品符文中择出四道天道符文的小游戏。
   - 破境丹可在冲击时自动消耗，成功率 +20%。
3. **历练**：45 张地图（每个境界恰有 2 幅可选 + 宗门秘境）、130+ 名敌人（含首领），
   出战消耗 2 行动点；胜后得灵石、兽核、药材，**战斗亦得修为**。妖兽偶带词缀
   （狂暴/坚甲/嗜血/灵体/护盾/迅捷），更强也更丰饶。历练页按境界分组：
   当前境界地图直列，往昔地界折叠可回访，远处地界折叠预览、随修为解锁。
4. **炼丹**：丹修十阶（丹童→丹帝），**618 张丹方**（含 9 张凝星丹方）随「丹修位阶 + 修为境界」**双重参悟解锁**；
   新式丹方按「品阶」取药，**2010 种灵植**皆可入药（从低品阶开始消耗），位阶越高成功率越高；
   丹成亦得修为。支持**批量炼制 x10 / x100**：一批只耗 1 行动点、逐炉判定，海量凝星丹药皆出于此。
   丹药分 12 大系：回气 / 聚灵 / 破境 / 洗髓 / 护命 / 清神 / 蓄元 / 启灵 / 行气 /
   锻体 / 罡气 / 凝神，各系自动取用最强者（破境、护命）。
5. **九星秘藏**：依序开启人体九大秘藏，每星皆有专属神通——风府星 修炼速度+25%、
   玉衡星 每日修为上限+30%、司命星 每日行动点+4、宫启星 攻击+30%、神关星 防御气血+30%、
   冥门星 掉落+50%、紫阙星 炼丹成功率+15%、涅冲星 战斗采药所得+50%、镇道星 全能+50%。
   每星需以专属**凝星丹**凝聚（九星九丹、共 54 枚，丹成品阶随机，丹道越高越易出高品）。
   **成星是毕生之功**：星丹化「丹力」灌入星窍，每一重都需海量丹药——星丹六品丹力
   普通 1 · 上品 4 · 特品 16 · 完美 64 · 神丹 256 · 巨丹 1024；星阶越高丹力越强，
   所需丹力星与星之间三倍而涨、重与重之间一倍半而涨（星 0 一重 10 丹力，
   星 8 末重逾 850 万丹力）。九星页有「一键凝聚」，逐枚吞丹直至丹尽或圆满。
   凝星十三重：星尘初聚、微芒始现、星火一点、星核初成、星环初绕、星纹天成、星魄内凝、
   星辉灌体、星海映身、星冕加顶、星劫淬真、星光通明、星汉圆满——**每凝一重神通即时递增，
   大圆满神通翻倍**。
6. **九星塔 · 武功阁**：九星塔行动点登塔，层层向上没有尽头；每 10 层一头守塔妖王，越层越强，
   里程碑层数掉落功法遗篇（长春功至九星真经）。「武功」页汇天下武学：**210 式战技、212 部功法**——
   开天七式随剧情与境界逐式传承（一式强过一式数倍），灭世火莲藏于仙界火候之中，
   大梵天经三卷分藏秘缘；传功阁中更有两百余式、两百余部以灵石/仙石购求。
   战技须装配入 **6 格战技栏** 方可施展（自动战斗亦只用栏中战技）；
   功法**运功多槽**：1 + 境界÷4，多部同修并济，境界越深运功越多。
7. **成就 · 悬赏 · 图鉴**：30 项成就（击杀/炼丹/登塔/开星……）领灵石与行动点；
   每日 3 条悬赏（除魔/猎首/采药/炼丹/服食/售货/闯塔），次日刷新，完成得灵石、修为与丹药；
   「大千图鉴」自动收录见过的灵植与丹药，灵植谱/丹药谱可按品阶筛选。
8. **养成**：装备淬炼可强化至 +10（每级攻防气血 +8%）；灵兽喂养升阶（至多 10 阶，产出随阶大增）。
9. **剧情任务**：30 段剧情（古墓斩邪刀、白骨将血饮刀、四国遗迹黑锅、紫血宗、凤鸣大比、
   命星涅槃、恶龙域、邪族裂隙、星空古路决战九天邪皇分身；另有凝星之引、开天七式七段传承、
   大梵天经三卷、蜕凡飞升、灭世火莲、仙界扬名、星汉圆满之路……）。
10. **凡界与仙界**：融天境为凡间之巅；蜕尽凡俗之气飞升**仙界**（蜕凡、神火之后仙道大盛），
    货币由**灵石**换作**仙石**（1 万下品灵石折 1 下品仙石），两者皆分
    **下品 / 中品 / 上品 / 极品**四等，相邻十倍——顶栏与商行金额自动换算显示。

## 三、日程系统（一天一天地过）

- 每日行动点 **22 点起**（随境界每境 +2），消耗：出战 2 · 采药 1 · 炼丹 1 · 祭骨 1 · 种植 1 · 浇灌 1 · 吐纳 1 · 登塔 2。
- **今日修为**：每日可获修为有上限（顶栏与修炼页可见），打坐/炼丹/战斗/采药/服食共同占用；
  上限随境界、混沌神树数量、九星（玉衡星）与功法提升。满额后需「日落而息」进入次日恢复。
- 当天没事做了？修炼页点击「**日落而息**」（或顶栏按钮）进入下一日：
  行动点回满、状态回复、灵植生长、灵兽产出、神树需要浇灌。
- **状态（0–100%）**：影响修炼速度与战斗属性。过夜回复
  `+8 基础 + 每株存活混沌神树 +5`；若混沌神树全部枯萎，每日仅 +8（回复缓慢）。
- 状态低于 40% 时会得到提醒；顶栏与修炼页随时可见。

## 四、混沌珠（凝血境后剧情获得）

混沌前辈赠予的至宝，内藏小世界，**空间无边无际**：

- **灵植园**：种丹药材料——选品阶、再从当档 2010 种灵植中挑选，随境界解锁更高品阶；
  种下 N 日成熟、收获多株。千种灵植皆可种。
- **混沌神树**：至多 9 株（暗合九星）。每株存活神树每日状态回复 +5；每株每日茂盛度 -25，
  需不定期「浇灌」（1 行动点，全体 +25）。**若神树尽枯，状态回复缓慢（仅 +8/日）**；
  枯树可花灵石「复苏」。「树下吐纳」可额外回复状态。
- **灵兽栏**：玉蜂群（产灵草）、灵狼崽（产兽核）、灵牛崽（产灵石），每日产出；
  喂 5 株同种灵植可升 1 阶（至多 10 阶），产出随阶大增。

## 五、华云商行（买卖）

- **采购**：灵草×10、兽核、祭骨丹、回气丹、聚灵坠（修炼+35%，仅此一件）。
- **出售**：千种灵植按品阶整批收购（可「留 10 株」再全售）、兽核、多余丹药——换灵石再投入修行或珠内经营。

## 八、手机上游玩（随时随地）

游戏已部署为 PWA（可安装、可离线的网页应用），手机与电脑不在一起也能玩：

- **网址**：`https://<你的GitHub用户名>.github.io/<仓库名>/`（部署后见 deploy.bat 输出）
- **装到桌面（像 App 一样）**：
  - Android（Chrome / Edge）：菜单 →「添加到主屏幕 / 安装应用」
  - iOS（Safari）：分享 →「添加到主屏幕」
- **离线可玩**：首次联网打开后自动缓存全部资源，之后**断网也能玩**；
  进度保存在手机本机。
- **进度带到另一台设备**：「境界」页 →「存档管理」→ 复制存档码，
  在另一台设备上粘贴导入即可（注意导入会覆盖该设备当前进度）。
- **自己部署 / 更新版本**：
  1. 在 https://github.com/new 创建一个空仓库（不要勾选 README 等初始化选项）
  2. 本目录下运行 `deploy.bat 你的用户名/仓库名`（首次推送会弹浏览器登录 GitHub）
  3. 打开仓库 Settings → Pages → Branch 选 `main` / `(root)` → Save，一两分钟后生效
  4. 以后改完代码重新 `deploy.bat` 推送即可；手机上若显示旧版，关掉页面重开一次

## 十一、快速上手（新手引导）

1. 开局看完序章，点「运转周天」攒灵气，灵气满层点「冲击」。
2. 攒够灵石先去「历练→凤鸣城郊」采药卖钱，行囊/商行随手卖货。
3. **凝血境**触发剧情「混沌赠珠」→ 珠内页：先种灵草、买玉蜂群攒药材。
4. **锻骨境**拼命赚钱买祭骨丹（商行有售），祭骨冲关。
5. 每天记得：做悬赏、采药、炼丹、种树、浇水、登九星塔；修为计满就「日落而息」。
6. 炼好「凝星丹」去九星页凝聚星窍——成星是毕生之功，海量丹药逐重累积（支持一键凝聚），
   直至十三重「星汉圆满」神通翻倍；融天境圆满后飞升仙界，灵石换仙石，开天七式与灭世火莲伴你征战仙界。
